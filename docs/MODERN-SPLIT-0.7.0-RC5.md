# rc5 — remove the API31+ split-screen block

The screenshot's toast was generated by rc4's SDK>30 early return. It therefore confirms the running build reported API31 or newer; it does not match the earlier head unit screenshot's SDK27. No assumption is made that the two screenshots came from the same device.

- API26–31: keep legacy Accessibility split action docking, with manual Recent Apps fallback when the ROM rejects the action.
- API32+ (Android12L onward): use the public adjacent-Activity launch path from the dedicated resizable dashboard, including NEW_TASK. No Accessibility grant is required for this path. Pressing B can open it directly when BitChord is installed.
- Remove the blanket SDK rejection. If automatic splitting is ignored, the side dashboard reports the runtime API and instructions for manual split when the user returns. A paused/invisible Activity does not open a fallback dialog over the other app.
- The modern intent is an attempt managed by Android; it is not a guarantee of OEM multi-window support or an embedded child Activity. The Android divider controls size. BitChord remains a separately installed app.
